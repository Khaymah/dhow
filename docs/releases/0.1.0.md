# داو 0.1.0

## أهم التغييرات

- **مساعدة داخل التطبيق.** في رأس كل صفحة زر **مساعدة** يفتح صفحتها في الوثائق بلغة الواجهة، وسطر قصير يشرح الصفحة.
- **صفحة الأسئلة الشائعة.** تعمل بدون اتصال بالإنترنت، وفيها بحث. تجدها في **المساعدة**.
- **عن داو.** صفحة تعرض النسخة وحالة السيرفر وفحوصاته والترخيص.
- **الإشعارات.** يرسل داو بريدًا أو webhook موقّعًا عند فشل نشر أو انتظاره موافقة. راجع [الإشعارات](../guides/notifications.md).
- **سجل التشغيل.** بحث في السجل، ورابط لسطر محدد، وتنزيل. راجع [تابع التشغيلات](../guides/jobs.md).
