# الأسرار والمتغيّرات

السر قيمة لا يجب أن يراها أحد، مثل مفتاح SSH أو رمز API. المتغيّر قيمة عادية تحتاجها خطوات النشر، مثل عنوان السيرفر. حساب سجل الصور يسمح لداو بقراءة صورة خاصة.

داو يحفظ السر مشفّرًا، ولا يعرضه مرة أخرى بعد الحفظ أبدًا. لا يوجد في الواجهة ولا في الـ API أي طريقة لقراءة قيمة سر، حتى لصاحب المؤسسة. إذا نسيت القيمة، اكتب قيمة جديدة.

حتى تصل مرحلة التوصيل (M5.5)، الأسرار محفوظة فقط ولا تصل إلى الـ jobs بعد.

## أين تحفظ السر

| المكان | من يستخدمه |
|---|---|
| المؤسسة | كل مشاريع المؤسسة، أو مشاريع تختارها أنت |
| المشروع | كل الـ jobs في المشروع |
| البيئة | الـ jobs التي تكتب اسم هذه البيئة في `environment:` فقط، بعد أن تسمح لها البيئة بالنشر |

يمكن أن يوجد الاسم نفسه في أكثر من مكان. الأقرب يكسب: البيئة، ثم المشروع، ثم المؤسسة. يظهر في القائمة أن السر «يغطي على» سر المؤسسة أو المشروع (`Overrides`).

تنفيذات الـ pull requests من مستودع منسوخ (fork) لا تأخذ أي سر ولا متغيّر أبدًا. وتنفيذات الـ pull requests من المستودع نفسه لا تأخذ أسرار المؤسسة أو المشروع، إلا إذا فعّلت `AvailableToPullRequests` على السر. أسرار البيئة تتبع قواعد البيئة.

## من يستطيع ماذا

| الإجراء | الدور |
|---|---|
| رؤية أسماء الأسرار وتفاصيلها (دون القيمة) | المطوّر وأعلى على المشروع، ومفاتيح API التي لها `secret.read` |
| كتابة أسرار المشروع ومتغيّراته وحسابات سجلاته | مسؤول المشاريع وأعلى على المشروع |
| كتابة أسرار المؤسسة ومتغيّراتها وحسابات سجلاتها | المدير وصاحب المؤسسة |
| كتابة أسرار البيئة ومتغيّراتها | من يدير البيئة (المدير وصاحب المؤسسة) |
| رؤية المتغيّرات وقيمها | كل من يرى المشروع |

مفاتيح API لا تكتب سرًا أبدًا. الكتابة من جلسة في المتصفح فقط، وتحتاج إلى خطوة ثانية إذا كانت سياسة مؤسستك تطلبها.

## كتابة سر

```http
PUT /api/v1/organizations/{id}/projects/{projectId}/secrets/DEPLOY_TOKEN
{"Value": "the secret value", "Description": "Deploy token for the API"}
```

الطلب نفسه ينشئ السر أو يكتب إصدارًا جديدًا منه. الرد فيه الاسم والإصدار والحجم، ولا يحتوي على القيمة.

- **الاسم:** حروف إنجليزية وأرقام و`_`، ولا يبدأ برقم، حتى 64 حرفًا. حالة الحروف لا تهم: `Token` و`TOKEN` سر واحد. الأسماء التي تبدأ بـ `DHOW_` محجوزة.
- **القيمة:** نص من 8 بايت حتى 32 كيلوبايت. القيمة الأقصر يصعب إخفاؤها في السجلات. اكتب المفاتيح الثنائية بصيغة base64.
- **العدد:** 500 سر للمؤسسة، و200 للمشروع، و100 للبيئة.

سر المؤسسة يقبل `Visibility`: القيمة `all_projects` لكل المشاريع، أو `selected_projects` مع `ProjectIds` للمشاريع المختارة فقط.

## الإصدارات

كل كتابة تنشئ إصدارًا جديدًا. نحتفظ بقيمة آخر 5 إصدارات فقط، ونمسح قيمة أي إصدار قديم بعد 30 يومًا من كتابة إصدار أحدث. الإصدار الحالي لا يُمسح.

```http
POST /api/v1/organizations/{id}/projects/{projectId}/secrets/DEPLOY_TOKEN/restore-version
{"Version": 3}
```

الإرجاع يكتب قيمة الإصدار القديم كإصدار جديد. إذا كانت قيمته قد مُسحت، يرد بـ `SECRET_VERSION_ERASED`.

حذف السر (`.../remove`) يمسح قيم كل إصداراته في الحال. وحذف البيئة يمسح أسرارها ومتغيّراتها ومفتاح تشفيرها.

## المتغيّرات

```http
PUT /api/v1/organizations/{id}/projects/{projectId}/variables/DEPLOY_HOST
{"Value": "app.example.com"}
```

المتغيّر له الأماكن نفسها وترتيبها، وقواعد الاسم نفسها. القيمة نص حتى 4 كيلوبايت، و256 متغيّرًا في كل مكان. المتغيّر ليس سرًا: كل من يرى المشروع يقرأ قيمته، فلا تضع فيه كلمة سر.

## حسابات سجلات الصور

```http
POST /api/v1/organizations/{id}/projects/{projectId}/registry-credentials
{"Host": "ghcr.io", "Username": "deploy-bot", "Password": "the registry token"}
```

- **السجل:** اسم فقط، مثل `ghcr.io` أو `registry.example.com:5000`، دون `https` ولا مسار. لا نقبل عنوان IP. `docker.io` يُحفظ باسم `registry-1.docker.io`، لأن الصور تُسحب منه.
- **مكانه:** المؤسسة لكل مشاريعها، أو المشروع. حساب المشروع يكسب على حساب المؤسسة للسجل نفسه. حساب واحد لكل سجل، و20 في كل مكان.
- **كلمة المرور:** لا تظهر بعد الحفظ أبدًا. التعديل (`PUT .../registry-credentials/{credentialId}`) يغيّر اسم المستخدم وكلمة المرور معًا.

يستخدم السيرفر الحساب عندما يثبّت صورة بالـ digest. يرسله إلى السجل نفسه فقط، وإلى خدمة الرموز إذا كانت على السجل نفسه بـ `https` (أو `auth.docker.io` لـ Docker Hub). تنفيذات الـ forks تثبّت الصور دون أي حساب.

## سجل الأحداث

كل كتابة وحذف وإرجاع يُسجَّل باسم السر ومكانه ورقم الإصدار فقط: `secret.created` و`secret.updated` و`secret.version_restored` و`secret.removed`، ومثلها للمتغيّرات (`variable.*`) وحسابات السجلات (`registry_credential.*`). لا يحتوي أي حدث على قيمة أو طولها.
