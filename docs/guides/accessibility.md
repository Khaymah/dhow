# سهولة الوصول

نريد أن يستطيع كل شخص استخدام داو: بلوحة المفاتيح فقط، أو بقارئ شاشة، أو بتكبير الصفحة، أو مع تقليل الحركة. هذه الصفحة تشرح ما تدعمه الواجهة اليوم، وكيف نفحصه، وكيف تبلغنا عن مشكلة.

## ما تدعمه الواجهة

| الميزة | ما تفعله |
|---|---|
| لوحة المفاتيح | كل زر ورابط وحقل يمكن الوصول إليه بالزر Tab، وتفعيله بالزر Enter أو Space. التبويبات تتحرك بالأسهم، وHome وEnd. |
| التركيز الظاهر | يظهر إطار أزرق حول العنصر المركّز في كل الثيمات، ولا يخفيه شريط ثابت أو لوحة. |
| تخطي إلى المحتوى | أول عنصر يصل إليه Tab رابط «تخطَّ إلى المحتوى». |
| أسماء الأزرار | كل زر أيقونة له اسم يقرؤه قارئ الشاشة. |
| حجم الهدف | كل عنصر يُضغط حجمه 24 بكسل على الأقل، وعلى الهاتف 44 بكسل للأزرار. |
| التباين | النص العادي بتباين 4.5 إلى 1 على الأقل في كل ثيمات النظام الأربعة، ويُفحص ذلك باختبار آلي. |
| اللغة والاتجاه | العربية من اليمين إلى اليسار هي الأصل، والإنجليزية من اليسار إلى اليمين، وتتغير سمتا `lang` و`dir` مع اللغة. |
| الحركة | عند تفعيل «تقليل الحركة» في النظام تتوقف الحركات والانتقالات. |
| مكان المساعدة | زر المساعدة له مكان ثابت في رأس كل صفحة، وهو فارغ إلى أن تصل المساعدة داخل التطبيق. |

## اختصارات لوحة المفاتيح

| الاختصار | الفعل |
|---|---|
| `Ctrl+K` أو `Cmd+K` | فتح لوحة الأوامر والبحث |
| `Tab` و`Shift+Tab` | الانتقال للعنصر التالي أو السابق |
| `Enter` أو `Space` | تفعيل الزر أو الخانة |
| `Esc` | إغلاق اللوحة أو الحوار |
| الأسهم و`Home` و`End` | التنقل بين التبويبات |

## كيف نفحص

- **فحص آلي في كل تغيير:** الاختبار `E2E/Accessibility.spec.ts` يشغّل مكتبة axe-core في المتصفح على صفحات الدخول، والرئيسية، والمشاريع، والتشغيل، والبيئة، والأعضاء، والإعدادات. يفحصها بالعربية والإنجليزية وبثيمات النظام الأربعة، ويفشل عند أي مخالفة خطيرة أو حرجة. المخالفات المتوسطة والبسيطة تُسجَّل في تقرير الاختبار ولا تفشله.
- **اختبارات الوحدة:** تتأكد من أسماء الأزرار، وحجم الخانات، وبقاء إطار التركيز، وترتيب Tab في المكوّنات الأساسية.
- **مراجعة يدوية قبل أول إصدار:** الفحص الآلي لا يكشف كل شيء، مثل ترتيب التركيز وما يقوله قارئ الشاشة. لذلك تُجرى قائمة يدوية بيد شخص، ويوقّع عليها باسمه ومشروعه وتاريخه، ولا يصدر أول إصدار قبل ذلك. القائمة في `Plan/A11y-Manual-Checklist.md`.

## حدود معروفة

- لم تُجرَّب الواجهة بعد مع قارئات الشاشة. ستُجرَّب في المراجعة اليدوية، وتُكتب نتيجتها هنا.
- مجموعة أزرار الاختيار تتوقف عند كل خيار بزر Tab بدل أن تتحرك بالأسهم داخل المجموعة. الاستخدام ممكن لكنه أطول.
- ثيمات النظام الأربعة كلها داكنة. لا يوجد ثيم فاتح بعد.
