# Dhow 0.1.0

## Highlights

- **Help inside the app.** The header of every page has a **Help** button that opens the page's documentation in the interface language, and a short line that explains the page.
- **A frequently asked questions page.** It works without an internet connection, and it has search. Find it in **Help**.
- **About Dhow.** A page that shows the version, the server's health and checks, and the license.
- **Notifications.** Dhow sends an email or a signed webhook when a deployment fails or waits for approval. See [Notifications](../guides/notifications.md).
- **The run log.** Search the log, link to a specific line, and download it. See [Follow runs](../guides/jobs.md).
