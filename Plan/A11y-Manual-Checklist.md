# قايمة سهولة الوصول اليدوية

**الحالة:** لسه ماتعملتش، ومحدش وقّع عليها.

القايمة دي من [ADR-0106](ADR/0106-accessibility-verification.md). الفحص الآلي (axe في `E2E/Accessibility.spec.ts`) مابيمسكش ترتيب التركيز ولا اللي بيقوله قارئ الشاشة، فالقايمة دي بتتعمل بإيد بشرية **قبل أول tag**. من غير توقيع تحت، ما فيش tag (معيار قبول M9).

## إزاي تتعمل

- على stack حقيقي (`make e2e` أو نسخة تجريبية)، بدخول مالك المؤسسة، وبيانات فيها مشروع وبيئة وتشغيل فيه موافقة منتظرة.
- كل بند يتجرّب بالعربي (RTL) وبالإنجليزي (LTR). والتباين يتجرّب في الأربع ثيمات (`sea` و`teak` و`dusk` و`indigo`).
- سجّل في جدول التوقيع: نسخة داو (من صفحة «عن داو»)، والمتصفح ونسخته، وقارئ الشاشة ونسخته، وصوته العربي. جرّب بقارئ واحد على الأقل (NVDA مع Firefox أو VoiceOver مع Safari)، والأفضل الاتنين.
- لو بند فشل: يتفتح issue بعنوان «سهولة الوصول: ...»، ويتكتب رقمه جنب البند، ومايتوقّعش لحد ما يتصلّح أو يتسجّل حد معروف في `docs/guides/accessibility.md`.

## 1. لوحة المفاتيح بس (من غير ماوس)

المسارات: الدخول، والتنصيب، والبحث بـ `Ctrl+K`، وفتح مشروع، وفتح تشغيل، وزرار تشغيل جديد، والموافقة على تشغيل، وتعديل بيئة وسر، وإضافة عضو.

- [ ] كل عنصر تفاعلي بيتوصّله بـ Tab، والترتيب يطابق الترتيب البصري (في RTL كمان).
- [ ] مفيش «فخ تركيز»: أي حوار أو شريحة أو لوحة بتتقفل بـ Esc والتركيز بيرجع للعنصر اللي فتحها.
- [ ] التركيز ظاهر دايمًا ومش مخفي ورا الشريط السفلي أو الشريحة (WCAG 2.4.11).
- [ ] رابط «تخطَّ إلى المحتوى» بيشتغل ويحط التركيز على `main`.
- [ ] التبويبات بتتحرك بالأسهم وHome وEnd، واتجاه الأسهم صح في RTL.
- [ ] مجموعات الاختيار (`ChoiceList`) والـ checkboxes بتتفعّل بـ Space.
- [ ] مفيش حاجة بتحتاج hover بس عشان تتفتح.

## 2. قارئ الشاشة

يتجرّب على: الدخول، والنشر (تشغيل جديد)، والموافقة. (NVDA مع Firefox أو Chrome على Windows، وVoiceOver مع Safari على macOS، وTalkBack على الموبايل لو متاح.)

- [ ] عنوان الصفحة (`h1`) بيتقري، وفيه عنوان واحد لكل صفحة.
- [ ] كل زرار أيقونة له اسم مفهوم، والاسم بيقول الفعل.
- [ ] كل حقل له تسمية، وأخطاء النموذج بتتقري وبتتربط بالحقل.
- [ ] حالات التحميل والفراغ والخطأ بتتعلن من غير ما المستخدم يدور عليها.
- [ ] حالة التشغيل (نجح وفشل ومنتظر موافقة) بتتقري كنص مش بلون بس.
- [ ] الـ landmarks (القايمة الجانبية، والـ main، والتنقل السفلي على الموبايل) متسمّية ومش مكرّرة.
- [ ] تغيير اللغة بيغيّر نطق النص (`lang`) من غير ما يضيع التركيز.

## 3. التكبير 200%

- [ ] الصفحات الأساسية على 200% وعرض 1280px: مفيش نص بيتقص، ومفيش تمرير أفقي للصفحة (WCAG 1.4.4 و1.4.10).
- [ ] نفس الشيء على 400% (عرض 320px): المحتوى بيتحوّل لعمود واحد.
- [ ] تكبير الخط فقط من إعدادات المتصفح بيشتغل.

## 4. حركة أقل

- [ ] مع `prefers-reduced-motion: reduce` مفيش حركة ولا انتقالات في الشرايح واللوحات والـ skeleton.
- [ ] مفيش حاجة بتومض أكتر من ثلاث مرات في الثانية.

## 5. التباين في الثيمات التلاتة (الأربعة فعليًا)

- [ ] النص العادي 4.5:1 والنص الكبير والأيقونات والحدود المهمة 3:1 على `sea` و`teak` و`dusk` و`indigo` (مقياس: أداة تباين على لقطة شاشة).
- [ ] الحالات (نجح وفشل وتحذير) مفهومة من غير لون بس.
- [ ] ثيم مخصّص بألوان من المستخدم: محرّر الثيمات بيحذّر لما التباين ينزل.

## 6. أهداف الضغط (WCAG 2.5.8)

- [ ] كل هدف ضغط 24×24px على الأقل، و44px للأزرار على الموبايل.

## 8. تدفقات كاملة

مسارات من أولها لآخرها بقارئ الشاشة ولوحة المفاتيح، مش صفحات لوحدها. لو اللي سمعته مش مفهوم، اكتبه في الملاحظات.

| التدفق | الخطوات | المطلوب | ك | ر | ز | ح | ملاحظات |
|---|---|---|---|---|---|---|---|
| الدخول بكلمة السر وكود التطبيق | افتح `/login`، اكتب البريد وكلمة السر، ثم الكود. | القارئ يقول «الخطوة الثانية» عند الانتقال. الخطأ في الكود يُقرأ. لا يُطلب منك حفظ شيء في ذاكرتك (WCAG 3.3.8). | ☐ | ☐ | ☐ | ☐ | |
| الدخول بمفتاح مرور | اختر الدخول بمفتاح المرور. | الحوار يُقرأ، والرجوع بعد الإلغاء يعيد التركيز لزر المفتاح. | ☐ | ☐ | ☐ | ☐ | |
| التنصيب الأول | افتح رابط الإعداد. | الخطوات مرتبة، والأخطاء تُقرأ، وكلمة السر تقبل اللصق. | ☐ | ☐ | ☐ | ☐ | |
| قبول دعوة | افتح رابط دعوة. | الحقول بأسمائها، ولا تُعاد كتابة بيانات سبق إدخالها (WCAG 3.3.7). | ☐ | ☐ | ☐ | ☐ | |
| الشرائح (كل نموذج في شريحة) | افتح شريحة من زر، اكتب، اضغط Esc. | التركيز يدخل الشريحة، ويبقى داخلها، ويعود للزر الذي فتحها عند الإغلاق. الصفحة خلفها لا يقرؤها القارئ. إغلاق شريحة فيها تعديلات غير محفوظة يسأل أولًا. القارئ يقرأ عنوان الشريحة عند الفتح. | ☐ | ☐ | ☐ | ☐ | |
| نتيجة الإرسال | احفظ نموذجًا ناجحًا وآخر فاشلًا. | رسالة النجاح والفشل تُقرأ دون أن يتحرك التركيز بعيدًا. التنبيه المؤقت (toast) يبقى وقتًا كافيًا ويُقرأ. | ☐ | ☐ | ☐ | ☐ | |
| موافقة نشر | في «الموافقات» اختر «وافق وانشر»، ثم جرّب الرفض والتخطي. | الشريحة تقول القرار والبيئة. الخطوة الثانية (كلمة السر أو الكود) تُقرأ. بعد القرار يُقرأ الإعلان بالنتيجة. | ☐ | ☐ | ☐ | ☐ | |
| لوحة النشر أثناء نشر | افتح اللوحة وابدأ نشرًا على هدف فيه أكثر من سيرفر. | تقدّم الدفعات يتغير دون إعلان كل ثانية. تغيّر الحالة النهائي (نجح، فشل) يُعلن مرة واحدة. شارة «فشل الرجوع» تُعلن. | ☐ | ☐ | ☐ | ☐ | |
| الفحص والرجوع على هدف | من اللوحة اضغط «افحص الهدف» ثم «الرجوع إلى إصدار سابق». | تأكيد الرجوع يحمل اسم الهدف. زر الرجوع المعطّل يقول السبب (النشر متوقف في البيئة). | ☐ | ☐ | ☐ | ☐ | |
| عارض السجل | افتح تشغيلًا بسجل طويل. اضغط `/` للبحث، ثم Enter للنتيجة التالية، ثم End لآخر سطر. | قائمة السطور لا تقرأ كل سطر جديد تلقائيًا. منطقة الحالة المنفصلة تقول «32 سطر جديد» (قرار 3 في M7). البحث يقول «النتيجة 2 من 9». «حمّل الأسطر الأقدم» و«نزّل السجل» لهما اسم. نسخ رابط سطر يعلن «نسخنا رابط السطر». طيّ الخطوة يقول «الخطوة مطوية». الاختصار `Ctrl+F` في المتصفح لا يرى السطور خارج الشاشة، فتأكد أن البحث الداخلي هو الطريق الموصوف. | ☐ | ☐ | ☐ | ☐ | |
| التحديث المباشر والرجوع للاستطلاع | أوقف الشبكة ثانية ثم أعدها، أو افتح الصفحة خلف وسيط يقطع البث. | الإشارة «التحديث المباشر متوقف» تُقرأ مرة واحدة. لا تظهر رسائل متكررة. | ☐ | ☐ | ☐ | ☐ | |
| لوحة الأوامر والبحث | اضغط `Ctrl+K` أو `Cmd+K`، اكتب، واختر بالأسهم. | القارئ يقول إنها حوار بحث، ويقرأ العنصر المحدد وعدد النتائج. Esc يغلقها ويعيد التركيز. | ☐ | ☐ | ☐ | ☐ | |
| الجرس وصندوق الإشعارات | استقبل إشعارًا جديدًا ثم افتح الجرس. | زر الجرس يقرأ الاسم مع عدد غير المقروء («افتح الإشعارات، وغير المقروء: 3»). فتح الإشعار ينقلك إلى صفحته. | ☐ | ☐ | ☐ | ☐ | |
| تغيير اللغة | بدّل بين العربية والإنجليزية. | القارئ يبدّل الصوت. الاتجاه يتغير ولا تنكسر الأرقام والنصوص المختلطة (أسماء الملفات والأوامر تبقى مقروءة). | ☐ | ☐ | ☐ | ☐ | |
| الثيم المخصص | افتح محرر الثيم وأنشئ ثيمًا. | حقول المحرر بأسمائها. جرّب ثيمًا ضعيف التباين: هل يظهر تحذير يُقرأ؟ إن لم يظهر، سجّل ذلك في الملاحظات. | ☐ | ☐ | ☐ | ☐ | |
| المساعدة داخل الصفحة | اضغط زر «مساعدة» في رأس أي صفحة. | الزر في مكان ثابت في كل الصفحات (WCAG 3.2.6). يقول إنه يفتح تبويبًا جديدًا. | ☐ | ☐ | ☐ | ☐ | |
| تخطي إلى المحتوى | عند فتح أي صفحة اضغط Tab مرة واحدة. | أول عنصر هو «تخطَّ إلى المحتوى» وينقل التركيز إلى العنوان الرئيسي. | ☐ | ☐ | ☐ | ☐ | |
| الهاتف | افتح التطبيق بعرض 390 بكسل وبقارئ الشاشة على الجوال (VoiceOver أو TalkBack). | الشريط السفلي بخمسة أسماء يُقرأ، وأهداف اللمس 44 بكسل. | ☐ | ☐ | ☐ | ☐ | |

## كيف نسجّل اللي لقيناه

- كل مشكلة في issue عنوانه يبدأ بـ «سهولة الوصول» ([المستودع](https://github.com/Khaymah/dhow/issues))، ومعاه الصفحة واللغة والثيم والمتصفح وقارئ الشاشة واللي سمعته واللي كان متوقع.
- **مانعة:** مش قادر تكمّل تدفق (دخول، نشر، موافقة، قراية السجل). بتتصلّح قبل التوقيع.
- **مش مانعة:** بتكمّل بصعوبة. بتتسجّل في «حدود معروفة» في [`docs/guides/accessibility.md`](../docs/guides/accessibility.md) وتتعالج بعدين.
- بعد كل إصلاح، أعد الصف المتأثر لوحده، وبعده الصفوف اللي بتشاركه في المكوّن.
- أماكن الفحص الآلي (axe) مكتوبة في `apps/web/E2E/Places.ts`. اللي مش فيه (شرايح التعديل، وإزالة عضو، وقرارات الموافقة) لازم يتجرّب هنا بإيدك.
